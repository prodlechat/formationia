## Mise en ligne via GitHub Pages

1. Repo en `Public` (Settings → Danger Zone → Change visibility)
2. Settings → Pages → Source: `main` branch, `/ (root)` → Save
3. URL en ligne sous 1-2 minutes : `https://prodlechat.github.io/formationia/`

## Stack

- HTML5 + CSS3 vanilla (zéro dépendance JS)
- Police Manrope + Inter via Google Fonts
- Responsive 3 paliers (desktop / tablette ≤ 860px / mobile ≤ 480px)
